01 · 연결 준비

원천과 대상 DB

원천은 필요한 메타데이터와 데이터만 읽을 수 있는 계정을 사용합니다. 설정 저장 후 실제 구조 조사에서 연결 결과를 확인하세요.

연결 범위 확인

SSH 터널·VPN·인증서·외부 JDBC 드라이버는 실행기 PC에서 먼저 준비해야 합니다. URL에는 비밀번호나 토큰을 넣지 마세요. 대상 DB의 실제 연결과 계약은 계획·검증 단계에서 확인합니다.

02 · 원천 자료

소스와 스키마 자료

이 PC에서 읽을 수 있는 소스 폴더를 지정하거나 파일을 가져옵니다. 등록만으로 코드 실행·의존성 설치·운영 적재를 시작하지 않습니다.

로컬 소스 폴더

브라우저가 실행되는 PC가 아니라 로컬 실행기가 읽는 경로입니다. 분석할 모듈 루트를 지정하세요.

파일 가져오기

이 로컬 실행기에만 전송합니다. ZIP 검사는 경로·개수·해제 크기 제한을 적용합니다. DDL은 구조 자료로 다루며 실행하지 않습니다.

현재 등록 자료

등록 상태를 확인하고 있습니다.

ZIP 해제 전 확인

아직 해제하지 않음

제외 목록과 해제 범위를 확인하세요. 실행기는 별도 작업 디렉터리에 해제하며 원본 코드를 실행하지 않습니다.

03 · 검토와 확정

용어·변환 원장

형식 2 원장을 가져와 초안을 편집합니다. 저장은 운영 승인이나 검증 통과를 뜻하지 않습니다.

초안 · 검증 대기

표준사전과 소스 근거를 확인해 사람이 확정해야 합니다. 원장 변경 후 이전 계획·검증 결과의 유효성을 다시 확인합니다.

컬럼별 표준 용어 검토

같은 원천 테이블·컬럼의 실제 후보만 표시합니다. PROPOSED 행의 용어와 메모만 편집하며, 확정·이관 제외·승인 이력은 만들지 않습니다. 후보의 적합률은 분석 당시 추정이며 용어 선택만으로 변환·대사 검증이 완료되지 않습니다.

용어 후보 생성 후 서버 원장과 근거를 불러오세요.

고급 · JSON 전체 구조 편집

표와 JSON은 같은 초안입니다. JSON을 직접 변경하면 ‘편집한 JSON을 표에 반영’을 눌러 다시 비교하세요. 미저장 내용은 브라우저 메모리에만 있으며 탭을 닫으면 사라집니다.

기존 CLI JSON 파일 가져오기

고급

현재 가져오기는 JSON만 지원합니다. 매핑·계획은 현재 입력으로 생성합니다. CLI가 생성한 YAML 결과는 보기·다운로드할 수 있습니다.

기관 검토 확정본 선택

고급
