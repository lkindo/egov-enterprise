## 테스트 개요

- **테스트 일시**: 2026-04-01 (미실행)

- **시나리오**: users-1000 (ramping-vus)
- **테스트 기간**: 20 분 (5 분 ramp-up, 10 분 steady, 5 분 ramp-down)

## 테스트 환경

### 서버 환경
- **URL**: http://localhost:8080
- **프로파일**: test
- **DB**: PostgreSQL 14 (localhost:5432)

### 클라이언트 환경
- **Tool**: k6 v1.7.1
- **OS**: Windows 11

## 실행 명령

```powershell
k6 run --scenario users-1000 test/load-tests/scenarios/load-levels.js
```
