현재 상태 판정

메커니즘은 성숙, 콘텐츠가 결손.

data-brand-theme 속성 스왑 + 키 패리티 계약 + 4.5:1 대비 수학 검증이라는 기계는 완성돼 있으나 색 축만 쓰고 있다. 밀도·형태·타이포 토큰은 0종 — 컨트롤 높이·셀 패딩·페이지 폭이 Tailwind 리터럴로 박혀 있어 프로필이 갈아끼울 대상 자체가 없다.

밀도 인플레이션은 4곳에 집중돼 있다.

프리미티브(button h-9, table p-2)는 이미 compact하다. 부풀리는 것은 래퍼 3개 — StandardDataTable(px-6 py-5), StandardSearchFilter(h-12/p-8) — 와 layout.tsx의 max-w-7xl 한 곳이다. 여기만 토큰화하면 전 화면이 따라온다.

ERP 최대 갭은 스타일이 아니라 기능이다.

열 정렬(aria-sort 0건)·page-size 선택·컬럼 리사이즈/숨김·인라인 편집·전체 결과 export·인쇄가 전부 부재. 624줄 자체 그리드를 57개 화면이 소비하므로, facade 뒤 headless 교체가 최대 지렛대다.

프레임워크 축은 "설계 과잉 · 실행 증거 결손".

생성기·census·계약은 성숙하나 공식 릴리스 태그 0개, 생성된 base는 메뉴/권한 시드 부재로 day-1 관리자 잠금, 코어에 BBSMSTR_* 데모 하드코딩 잔존 — 전부 재설계가 아닌 마감 작업이다.

실행 단계

Phase 번호는 실제 의존 순서다. Track B(프레임워크 축)는 파일 충돌이 거의 없어 Phase 1부터 병행한다. 오늘 시작은 결정 불요, D#는 아래 결정 목록의 한 문장 승인이 선행 조건.
