## 1. 테스트 개요

### 1.1 테스트 목적

본 테스트는 k6 를 사용하여 egov-enterprise 시스템의 주요 API 엔드포인트에 대한 부하 테스트를 수행하고, 시스템의 성능 한계와 병목 지점을 식별하는 것을 목적으로 합니다.

### 1.2 테스트 범위

**대상 엔드포인트:**
- `POST /api/v1/login` - 사용자 인증
- `GET /api/v1/dashboard` - 대시보드 조회
- `POST /api/v1/boards/posts` - 게시글 등록
- `GET /api/v1/admin/system/users` - 사용자 목록 조회

**부하 레벨:**
- Level 1: 100 명 동시 사용자
- Level 2: 500 명 동시 사용자
- Level 3: 1000 명 동시 사용자

### 1.3 테스트 기간

- **계획**: 2026-04-01
- **실시**: 미정 (k6 설치 필요)

## 3. 테스트 시나리오

### 3.1 시나리오 개요

각 부하 레벨별로 다음 시나리오가 혼합되어 실행됩니다:

| 시나리오 | 비중 | 설명 |
|---------|------|------|
| 로그인 | 40% | 사용자 인증 요청 |
| 대시보드 조회 | 30% | 대시보드 데이터 조회 |
| 사용자 목록 조회 | 20% | 관리자용 사용자 목록 조회 |
| 게시글 등록 | 10% | 새 게시글 생성 |

### 3.2 부하 패턴

**100 명 시나리오 (users-100):**
- Ramp-up: 1 분 (0 → 100 VUs)
- Steady: 3 분 (100 VUs 유지)
- Ramp-down: 1 분 (100 → 0 VUs)
- **총 소요**: 5 분

**500 명 시나리오 (users-500):**
- Ramp-up: 2 분 (0 → 500 VUs)
- Steady: 5 분 (500 VUs 유지)
- Ramp-down: 2 분 (500 → 0 VUs)
- **총 소요**: 9 분

**1000 명 시나리오 (users-1000):**
- Ramp-up: 5 분 (0 → 1000 VUs)
- Steady: 10 분 (1000 VUs 유지)
- Ramp-down: 5 분 (1000 → 0 VUs)
- **총 소요**: 20 분

## 4. 성능 기준치 (SLO)

### 4.1 임계값

| 메트릭 | 기준치 | 설명 |
|--------|--------|------|
| HTTP 응답시간 (p95) | < 1000ms | 95% 요청이 1 초 이내 처리 |
| HTTP 실패율 | < 1% | 전체 요청의 1% 미만 실패 |
| 테스트 완료 시간 | < 300s | 전체 테스트가 5 분 이내 완료 |

### 4.2 부하 레벨별 목표

| 부하 레벨 | 동시 사용자 | 응답시간 (p95) | 목표 TPS |
|-----------|-------------|---------------|----------|
| Level 1 | 100 명 | < 500ms | > 100 TPS |
| Level 2 | 500 명 | < 800ms | > 400 TPS |
| Level 3 | 1000 명 | < 1000ms | > 800 TPS |
