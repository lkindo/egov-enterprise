# ADR-0049 — 워크플로우 목업 화면 퇴역과 기존 권한 배정 호환

- 상태: Accepted
- 결정일: 2026-11-01
- 승인: 사용자가 목업의 필요성을 질문한 뒤 "정리하고 메인에 머지까지 진행해줘"로 화면 정리와 병합을 요청했다.
- 대체 범위: `/admin/workflow`, `/admin/sanctn/workflow`, `/admin/sanctn/forms`의 V2_45 화면 보존 판단, 2026-08-23 `demo-isolated` 처분 승인과 [DEC-OPS-300](../../archived/operational-decisions-history.md#dec-ops-300)의 해당 화면 소유 선언을 대체한다. 시연 기능의 프런트 전용 경계와 권한 소유·서버 비사용 검사는 유지한다.

## 맥락

프로세스 설계 캔버스와 결재 양식 허브는 백엔드에 연결되지 않은 정적 목업이다. 실제 기안·다단계 승인·합의·반려·재상신은 `/approvals`가 제공하지만, 시각적인 결재선·결재 양식 설계기는 구현되지 않았다. `/admin/community/templates`는 커뮤니티·게시판 템플릿 원장이며 결재 양식 설계기가 아니다. 목업은 실제 결재의 실행 경로나 중복 구현이 아니며, 업무 기능 평가에서 미완성 제품으로 오인될 수 있다.

실수로 병합된 화면은 아니다. [V2_45](../../../api-server/src/main/resources/db/migration/V2_45__retire_sanction_form_studio_menus.sql)는 2026-08-06 사용자 승인으로 메뉴를 비활성화하면서 문자열 URL 참조의 오삭제 전례 때문에 화면 파일은 남겼다. 이후 `demo-isolated` 승인과 시연 기능 소유로 격리했다. 이번 결정은 이 파일 보존 판단을 대체한다. 현재 실행 참조·페이지 인가·리다이렉트·생성기 원장을 대조하고 실제 결재·템플릿 보존 및 퇴역 경로 거부 검사를 두어 삭제 위험을 낮춘다. 과거 SQL과 비활성 메뉴 행은 그대로 보존한다.

`WORKFLOW_READ`는 기존 DB의 그룹에 배정될 수 있다. [인증 스냅샷](../../../business-core/src/main/java/nuri/business/security/authorization/AuthorizationSnapshotService.java)은 저장된 OPERATION 코드가 소스 카탈로그에 없으면 인증을 실패시킨다. 화면을 지우면서 이 정의만 함께 삭제하면 기존 배정이 있는 환경을 깨뜨린다.

## 결정

1. 목업 3개 URL의 페이지·전용 컴포넌트·리다이렉트와 화면 등록·역량·처분 항목을 제거한다. 대체 업무 화면에 연결하지 않으며, 미등록 관리 URL을 거부하는 기존 [페이지 인가](../../../frontend/src/lib/auth/page-authorization.ts)를 유지한다. 로그인한 사용자가 옛 주소를 직접 열면 기존 인가 거부 처리로 `/?auth_error=unauthorized`에 도착한다.
2. 실제 `/approvals`와 `/admin/community/templates`의 동작·권한은 유지한다. 시연 기능에는 업무 화면 패턴·테마 설정·하네스 샘플을 남긴다.
3. `WORKFLOW_READ` 정의, 기존 기본 그룹 배정 선언, 시연 기능의 권한 소유는 기존 DB 인증 호환을 위해 유지한다. 이름과 권한 묶음 제외 사유에 종료된 목업의 호환 코드이며 실행 표면이 없음을 명시한다. 이 권한을 가진 사용자도 퇴역 URL을 열 수 없다.
4. DB 배정·메뉴 행·메뉴 스냅숏·적용된 SQL은 변경하지 않는다. 향후 권한 정의까지 삭제하려면 저장된 배정과 메뉴를 실측하고, 감사가 남는 회수·이행을 별도로 승인한다. 알 수 없는 권한을 허용하는 예외는 도입하지 않는다.
5. 목업 전용 테스트·E2E 파일·실측 시간 항목과 삭제된 코드의 동결 항목만 걷는다. 범용 시연 격리·투영 검사의 부정 사례는 남아 있는 시연 화면으로 옮기며, 실제 결재·템플릿과 미등록 URL 거부 검사는 보존한다.

## 영향과 검증 경계

제품 화면과 평가 모집단에서 목업이 사라진다. 예전 목업 주소는 더 이상 지원하지 않으며, 권한 목록의 호환 코드나 DB의 비활성 메뉴 행이 기능 제공을 뜻하지 않는다. `WORKFLOW_READ`는 완전히 회수된 권한으로 표현하지 않는다.

필요한 검증은 퇴역 경로의 미등록·진입 거부, 실제 결재·템플릿 경계 보존, 원장·생성물 일치, 시연 격리·투영 위반의 red 증명이다. 이 ADR은 검증 실행 결과나 운영 배포 증거가 아니며, 결과는 해당 커밋·PR·CI에 남긴다.
