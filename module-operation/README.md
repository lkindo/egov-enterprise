# Module Operation (사용자 운영 지원)

## 1. 개요
본 모듈은 일반 사용자가 관리자에게 상담을 요청하거나 전사적 설문조사에 참여하는 등 서비스를 직접적으로 소비하는 접점 기능을 수행합니다.

## 2. 주요 책임 (Responsibilities)
- **설문 서비스**: 진행 중인 설문에 참여(Response), 전체 결과 조회(일부 사용 가능).
- **고객 서비스(CS)**: 상담(Consultation) 요청 등록, Q&A(질의응답) 질문 등록 및 답변 확인.
- **공익 업무**: 약관(Terms) 상세 조회, 각종 행정 업무 지원 프로세스 담당.

## 3. 리팩토링 결과 (Refactoring Status)
- 설문지 폼 설계(Master) 및 상담/Q&A 답변(Admin Response) 등 관리자 운영 로직은 `module-system-admin`으로 완전 이관되었습니다.
- 사용자와의 인터랙션 로직(등록, 본인 내역 조회)에 충실하도록 경량화되었습니다.

## 4. 구조적 의미
본 모듈의 기능을 통해 사용자의 피드백이 수집되며, 수집된 데이터는 `module-system-admin`에서 통계 처리 및 답변 관리의 대상이 됩니다.
