## 🚀 E2E 테스트 기본 원칙 (Base Principle)
1. **무결성 검사**: 모든 테스트는 `ConsoleErrorGuard`를 통해 브라우저 콘솔 로그를 감시한다.
2. **엄격한 기준**: 단순 경고(Warning)라도 무시하지 않고 오류로 간주하여 해결한다.
3. **각개격파**: 다수의 실패 발생 시, 한 번에 하나씩 집중적으로 수정하고 해당 테스트를 즉시 검증한 후 다음 단계로 이동한다.
4. **어드민 계정**: `webmaster` / `1` 사용.
