## 테스트 명령어
- 백엔드 유닛 테스트: `./gradlew test -Dfile.encoding=UTF-8`
- 프론트엔드 유닛 테스트: `npm --prefix frontend run test`
- 프론트엔드 E2E 테스트: `npm --prefix frontend run test:e2e -- --project=full-suite`
- DB 클린업: `npm --prefix frontend run test:cleanup`
