# Specialized Subagents

이 스킬은 특정 도메인에 특화된 지식과 헌법을 탑재한 '전문 서브에이전트'를 정의합니다. 위임 시 해당 에이전트의 프롬프트를 로드하여 가장 정밀한 결과를 도출합니다.

## 에이전트 목록

1. **DB 서브에이전트 (`db-subagent.md`)**
   - 역할: 데이터베이스 설계, 표준화, 쿼리 최적화
   - 핵심 자산: DB 표준화 헌법

2. **백엔드 서브에이전트 (`backend-subagent.md`)**
   - 역할: API 설계, 비즈니스 로직 구현, 서버 아키텍처
   - 핵심 자산: 백엔드 API 헌법

3. **프론트엔드 서브에이전트 (`frontend-subagent.md`)**
   - 역할: UI/UX 구현, 컴포넌트 설계, 스타일링
   - 핵심 자산: 프론트엔드 UX 헌법

4. **테스트 서브에이전트 (`test-subagent.md`)**
   - 역할: QA, 테스트 코드 작성, 시나리오 검증
   - 핵심 자산: TDD 스킬, 웹 앱 테스팅 스킬

5. **보안 서브에이전트 (`security-subagent.md`)**
   - 역할: 인증/인가, 취약점 분석, 보안 규정 준수
   - 핵심 자산: 보안 거버넌스 가이드

## 활용 방법

위임 요청 시 다음과 같이 명령합니다:
- "이번 DB 작업은 **DB 서브에이전트** 모드로 실행해줘."
- "로그인 보안 검증은 **보안 서브에이전트**에게 위임해."
